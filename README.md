# ОБП — Объединённая больница с поликлиникой (УДП РФ)

Сайт ФГБУ «Объединённая больница с поликлиникой» Управления делами Президента РФ
в стиле «тихая роскошь»: тёплый белый холст, золотой корпоративный акцент
(извлечён из эмблемы больницы), серифный заголовочный шрифт Cormorant + гротеск
Manrope. Аудитория — состоятельные пациенты; акценты — сервис, качество и
конфиденциальность.

Из одностраничного лендинга проект вырос в **полноценный сайт из 13 связанных
страниц**. Главное целевое действие — **«Оставить заявку / Перезвоните мне»**
(модалка обратного звонка): новый пациент оставляет имя и телефон → ему
перезванивают и записывают → после визита заводится личный кабинет.

## Структура

### Многостраничный сайт (модуль `site/`)

```
index.html            — главная (имиджевый герой, направления, врачи, цифры)
about.html            — О больнице (история, миссия, цифры)
napravleniya.html     — Направления / отделения (обзор)
otdelenie.html        — Страница одного отделения (шаблон)
vrachi.html           — Врачи (список + фильтр)
vrach.html            — Карточка врача
tseny.html            — Услуги и цены (прейскурант)
programmy.html        — Программы и чек-апы
statsionar.html       — Стационар (палаты, условия)
diagnostika.html      — Диагностика (МРТ / КТ / УЗИ / лаборатория)
novosti.html          — Новости / статьи
patsientam.html       — Пациентам (документы, подготовка, ОМС/ДМС)
kontakty.html         — Контакты (карта, схема проезда)

site/site.css         — единая дизайн-система всех страниц
site/data.jsx         — общие данные (направления, врачи, цены, программы…)
site/shell.jsx        — Icon, шапка с мега-меню, футер, модалка обратного звонка, drawer
site/page-home.jsx    — главная страница
site/pages1.jsx       — О больнице, Направления, Отделение
site/pages2.jsx       — Врачи, Карточка врача, Цены
site/pages3.jsx       — Программы, Стационар, Диагностика
site/pages4.jsx       — Новости, Пациентам, Контакты
```

### Личный кабинет пациента

```
Личный кабинет.html    — самодостаточная страница (стили инлайн)
lk/lk-data.jsx         — данные ЛК + QR-компонент
lk/lk-auth.jsx         — экраны входа и восстановления пароля
lk/lk-screens.jsx      — дашборд, анализы, запись с сеткой расписания, пропуска, профиль
lk/lk-app.jsx          — оболочка ЛК (сайдбар, топбар, мобильная навигация)
```

Экраны ЛК: вход и восстановление пароля; дашборд (3 последних исследования +
крайний пропуск); список анализов со статусами; запись к врачу с сеткой
расписания; QR-пропуск с добавлением автомобиля; профиль. На телефоне сайдбар
сворачивается в нижнюю таб-панель.

### Общее

```
assets/               — эмблема и полный логотип больницы
ОБП - Главная.html     — редирект на index.html (старый лендинг заменён сайтом)
styles.css / sections.css / responsive.css, js/  — наследие старого лендинга
```

## Запуск

Страницы используют React 18 и Babel Standalone через CDN, поэтому достаточно
отдать файлы любым статическим сервером (открытие через `file://` не сработает
из-за загрузки `.jsx` через `<script src>`):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/
```
