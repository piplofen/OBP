# ОБП — Объединённая больница с поликлиникой (УДП РФ)

Редизайн главной страницы сайта ФГБУ «Объединённая больница с поликлиникой»
Управления делами Президента РФ. Современный, спокойный интерфейс в стиле
«тихая роскошь»: тёплый белый холст, золотой корпоративный акцент (извлечён из
эмблемы больницы), серифный заголовочный шрифт Cormorant + гротеск Manrope.

Главная задача страницы — **кратчайший путь пациента**: «хочу сдать анализ →
оплатил». Сценарий записи реализован сквозным flow в 4 шага: **выбор услуг →
дата и время → данные пациента → оплата → подтверждение** с номером заявки.

## Структура

```
index.html            — точка входа главной (идентична «ОБП - Главная.html»)
ОБП - Главная.html     — главная страница (исходный файл дизайна)
Личный кабинет.html    — личный кабинет пациента (самодостаточная страница, стили инлайн)
styles.css            — токены дизайн-системы, типографика, кнопки
sections.css          — вёрстка секций: шапка, герой, прейскурант, футер, flow записи
responsive.css        — адаптивный слой: планшет / телефон / узкий телефон, bottom-sheet записи
js/icons.jsx          — единый набор иконок + данные каталога (анализы, врачи, навигация)
js/booking.jsx        — slide-over записи и оплаты (ядро пользовательского пути)
js/components.jsx     — секции главной: Nav, Hero, Trust, Directions, PriceTeaser и др.
lk/lk-data.jsx        — данные ЛК + QR-компонент
lk/lk-auth.jsx        — экраны входа и восстановления пароля
lk/lk-screens.jsx     — экраны: дашборд, анализы, запись с сеткой расписания, пропуска, профиль
lk/lk-app.jsx         — оболочка ЛК (сайдбар, топбар, мобильная навигация) и монтирование
assets/               — эмблема и полный логотип больницы
```

## Личный кабинет пациента (`Личный кабинет.html`)

Самодостаточная страница в том же стиле «тихая роскошь». Экраны:

- **Вход и восстановление пароля** (форма с валидацией).
- **Главная (дашборд)** — кратко по 3 последних исследования/анализа и крайний пропуск.
- **Исследования и анализы** — список результатов со статусами.
- **Запись на приём** — выбор врача и сетка расписания со слотами.
- **Пропуска** — QR-пропуск и добавление автомобиля к пропуску.
- **Профиль пациента** — персональные данные.

На телефоне сайдбар сворачивается в нижнюю таб-панель. Ссылки «Личный кабинет»
на главной ведут на эту страницу.

## Запуск

Страница использует React 18 и Babel Standalone через CDN, поэтому достаточно
отдать файлы любым статическим сервером (открытие через `file://` не сработает
из-за загрузки `.jsx` через `<script src>`):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/
```

## Возможности

- **Шапка** с мега-меню по направлениям и липкой навигацией.
- **Герой** с блоком «Быстрая запись на анализы» (поиск + популярные исследования).
- **Сквозной flow записи** с переключателем «Анализы / Приём врача», выбором даты
  и времени, валидацией формы, выбором способа оплаты и выездом на дом.
- **Прейскурант** с прозрачными ценами и кнопкой «Добавить → оплатить».
- Блоки доверия, преимуществ, CTA, подробный футер.
- **Полный адаптив** (`responsive.css`): брейкпоинты планшет ≤1024px, телефон ≤760px,
  узкий телефон ≤520/380px; на телефоне окно записи превращается в bottom-sheet,
  шапка ниже 1080px — гамбургер-меню. Учтены тач-устройства и вырезы экрана
  (`viewport-fit=cover` + safe-area).
